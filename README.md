# QuickTranslate

Переводчик для macOS, который живёт в строке меню. Выделяешь текст в любой программе, жмёшь горячую клавишу — получаешь перевод. Умеет переводить веб-страницы прямо на месте, распознавать текст на скриншотах и картинках, озвучивать и причёсывать текст.

### ⬇️ [Скачать последнюю версию](../../releases/latest)

Нужен файл `QuickTranslate.dmg`.

---

## Требования

- macOS 15 (Sequoia) или новее
- Mac на Apple Silicon (M1–M4) или Intel
- Интернет

API-ключ вводить **не нужно** — он уже вшит в сборку, приложение работает сразу после установки.

## Установка

### 1. Скачать и перетащить

Открой ссылку выше → скачай `QuickTranslate.dmg` → дважды кликни по нему → перетащи **QuickTranslate** в папку **Applications**.

### 2. Первый запуск — обойти защиту macOS

Приложение не подписано сертификатом Apple, поэтому при первом запуске macOS его заблокирует. Это ожидаемо, так и должно быть.

1. Открой **Applications**, кликни по **QuickTranslate**.
2. Появится окно «Apple не удалось проверить, что приложение не содержит вредоносного ПО» → нажми **Done**.
3. Зайди в **System Settings → Privacy & Security**, пролистай вниз до строки про QuickTranslate → нажми **Open Anyway** → подтверди **Open**.

Если кнопки **Open Anyway** нет, открой **Terminal** (Программы → Утилиты) и выполни одну команду:

```bash
xattr -dr com.apple.quarantine /Applications/QuickTranslate.app
```

После этого приложение запускается обычным двойным кликом.

> Иконка приложения появится **в строке меню сверху**, рядом с часами. Окна в Dock не будет — так и задумано.

### 3. Выдать разрешения

Без них приложение не сможет прочитать выделенный текст. Всё в **System Settings → Privacy & Security**:

| Раздел | Зачем | Обязательно? |
|---|---|---|
| **Accessibility** | Читать выделенный текст и вставлять перевод на место | Да |
| **Screen Recording** | Перевод скриншотов, картинок и OCR (`⌥4`, `⌘5`, `⌘9`) | Да, если нужны эти функции |
| **Automation** (Safari / Chrome) | Перевод веб-страниц прямо на странице (`⌘8`) | Да, если нужен перевод страниц |

Если QuickTranslate не видно в списке — нажми **+**, выбери его в `Applications` и включи переключатель.

**Важно:** после включения Accessibility и Screen Recording приложение нужно перезапустить (иконка в строке меню → **Выход**, затем запустить заново).

## Как пользоваться

Выдели текст в любом приложении и нажми:

| Клавиши | Что делает |
|---|---|
| `⌘1` | Перевод выделенного на русский — во всплывающем окне |
| `⌘2` | Перевод на английский, копируется в буфер |
| `⌘3` | Перевод на испанский, копируется в буфер |
| `⌥4` | Выделить область экрана мышью → перевод того, что на ней (скриншот + OCR) |
| `⌘5` | Распознать текст с области экрана и скопировать **без** перевода |
| `⌘6` | Нормализовать текст: починить пунктуацию, орфографию, транслит |
| `⌘7` | Озвучить выделенное вслух |
| `⌘8` | Перевести страницу в браузере прямо на месте (повторное нажатие — вернуть оригинал) |
| `⌘9` | Перевести текст на изображении |
| `⌥9` | Живой перевод области экрана — для субтитров и стримов |
| `⌥` + наведение | Зажать Option и навести мышь на абзац в браузере — переведётся только он |

Все сочетания переназначаются: иконка в строке меню → **Настройки** → раздел **Горячие клавиши**.

### Что ещё есть в меню

- **Автоперевод страниц в браузере** — любая открытая страница на иностранном языке переводится сама.
- **История** — последние переводы с поиском.
- **Скрыть перевод-оверлей** — убрать наложенный перевод с экрана.

### Полезные настройки

В **Настройках** стоит заглянуть в:

- **Модель / Скорость** — баланс «быстро / качественно».
- **Качество перевода → Контекст предметной области** — опиши свою сферу работы, и термины будут переводиться точнее.
- **Глоссарий** — свои пары «термин = перевод», которые всегда переводятся именно так.
- **Позиция всплывающих окон** — где показывать popup.

## Если что-то не работает

**«Не удалось прочитать выделение»** — не выдан доступ в **Accessibility** либо приложение не перезапущено после выдачи. Проверь галочку и перезапусти QuickTranslate.

**Горячая клавиша не срабатывает** — сочетание занято другой программой. Назначь своё в `Настройки → Горячие клавиши`.

**Скриншот-перевод или OCR не работает** — нет доступа в **Screen Recording**. Выдай и перезапусти приложение.

**Перевод страницы (`⌘8`) не срабатывает** — нужно разрешение в **Automation** для твоего браузера. При первом нажатии macOS сам спросит — согласись.

**Пустой ответ или ошибка сети** — проверь интернет. Если пишет про `rate limit` — подожди минуту и повтори.

**Ничего не помогло** — `Настройки → Экспортировать логи`: соберётся ZIP с логами и диагностикой (без ключей и паролей), его можно отправить на разбор.
